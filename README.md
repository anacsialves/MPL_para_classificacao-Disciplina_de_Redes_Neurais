# MPL para problemas de classificação 
## Disciplina de Redes Neurais e Algoritmos Genéticos
Neste repositório exploramos as principais diferenças entre redes neurais do tipo Multilayer Perceptron regressoras e classificadoras, fornecendo um exemplo de rede feita com o módulo Lightning.

Ele foi feito com o objetivo de entrega de atividade proposta na disciplina de Redes Neurais e Algoritmos Genéticos oferecida no curso de Ciência e Tecnologia da Ilum pelo professor Daniel Roberto Cassar.

A sugestão de execução dos arquivos é a seguinte:
- Primeiro baixe os arquivos .ipynb e .pth em um mesmo diretório
- Execute o arquivo "Trilha da Academica - introdução.ipynb" para ser introduzido ao tema
- Executo o arquivo "Trilha da Academica - pytorch-lightning.ipynb" para ver a aplicação
  *O arquivo "Trilha da Academica - pytorch-lightning.ipynb" precisa que certas bibliotecas de python estejam instaladas em seu ambiente virtual, certifique-se de que as possui instaladas para que o notebook rode normalmente.
